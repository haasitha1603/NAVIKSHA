# NAVIKSHA

## AI Human Activity Recognition for On-board BAS Experiments

NAVIKSHA is an AI-powered Human Activity Recognition system
developed for Smart India Hackathon Problem Statement SIH26174.

The system is designed to recognize astronaut activities in
real time and provide intelligent activity insights for
on-board BAS experiments.
